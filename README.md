# Bongsho-Bistar-Game
This is a Recreation of the Game Color Wars
## Original Game was created by JindoBlu from "1234 player games" in play store

To Play Online, you must have a metered account, with an app created. Then by going to the TURN servers page, you must create a credential.
Using that credential you will receive an API key, which can then be pasted under the networking tools, under your app name.
Then run the test, and then create/host a room.
